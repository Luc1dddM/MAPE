# MAPE - Automatic Prompt Engineer

## Project Overview

MAPE (Automatic Prompt Engineer) is a full-stack TypeScript application for automated prompt engineering, evaluation, and optimization. It provides a comprehensive system for generating, testing, and improving AI prompts using various prompt engineering techniques with integrated evaluation and optimization workflows.

### Tech Stack
- **Frontend**: Next.js 14, React 18, TypeScript, Tailwind CSS
- **Backend**: Express.js, TypeScript, Node.js (ESM modules)
- **AI Integration**: Google Generative AI (Gemini)
- **Evaluation**: Promptfoo integration
- **Database**: Redis (caching)
- **State Management**: Zustand
- **Containerization**: Docker & Docker Compose

## API Endpoints

### Prompt Operations (`/api/prompts/`)
- `POST /generate` - Generate prompts using techniques
- `GET /techniques` - List available techniques
- `POST /evaluate` - Evaluate prompt effectiveness
- `POST /test` - Test prompt with input
- `POST /variations` - Generate prompt variations
- `POST /optimize` - Optimize existing prompt

### Evaluation Operations (`/api/evaluations/`)
- `POST /run` - Run new evaluation
- `GET /:id` - Get evaluation results
- `GET /:id/status` - Check evaluation status
- `GET /` - List all evaluations
- `DELETE /:id` - Delete evaluation
- `GET /meta/criteria` - Get evaluation criteria
- `GET /meta/providers` - Get AI providers

### Optimization Operations (`/api/optimize/`)
- `POST /prompt` - Main optimization endpoint
- `POST /analyze` - Analyze failure patterns
- `GET /history/:id` - Get optimization history
- `POST /compare` - Compare prompt performance
- `POST /suggestions` - Get optimization suggestions
- `POST /batch` - Batch optimize multiple prompts

# Workspace notes

- Optimize Tab Content Specification ## Overview Create content for the optimize tab that displays optimization results and the updated prompt based on the optimization process. ## Response Format The optimize tab will receive and display data from the following API response structure: ```json { "success": true, "data": { "originalPrompt": "string - The original user prompt before optimization", "optimizedPrompt": "string - The enhanced and optimized version of the prompt", "improvements": [ "string - List of specific improvements made to the prompt", "string - Each improvement describes what was enhanced", "string - Multiple improvement descriptions can be included" ], "metadata": { "originalLength": 1049, "optimizedLength": 3856, "clustersAnalyzed": 2, "optimizedAt": "2025-08-04T17:06:56.876Z", "promptId": "2d8b20a0-c7e0-42a7-b92f-03ede3f4d91e-prompt-0" } } } ``` ## Content Requirements ### Main Display Sections 1. **Optimization Results Summary** - Display success status - Show optimization completion timestamp - Present key metrics (original vs optimized length, clusters analyzed) 2. **Prompt Comparison** - **Original Prompt Section**: Display the `originalPrompt` content - **Optimized Prompt Section**: Display the `optimizedPrompt` content - Side-by-side or tabbed comparison view 3. **Improvements List** - Display all items from the `improvements` array - Format as bulleted or numbered list - Highlight key enhancements made during optimization 4. **Metadata Information** - Original prompt length: `originalLength` characters - Optimized prompt length: `optimizedLength` characters - Number of clusters analyzed: `clustersAnalyzed` - Optimization timestamp: `optimizedAt` - Unique prompt identifier: `promptId` ### Visual Layout Considerations - Clear section headers for easy navigation - Responsive design for different screen sizes - Appropriate spacing and typography for readability - Visual indicators for improvements (icons, colors, highlighting) - Copy-to-clipboard functionality for both original and optimized prompts ### Error Handling - Handle cases where `success` is `false` - Display appropriate error messages if optimization fails - Provide fallback content if any data fields are missing ### Interactive Features - Allow users to copy the optimized prompt - Toggle between original and optimized versions - Expand/collapse sections for better space management - Export functionality for the optimization results
